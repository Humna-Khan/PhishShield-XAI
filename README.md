# PhishShield-XAI

> **Real-Time Adversarial Phishing Detection with Explainable AI and Active Hardening**
> Track 5 — Final Project

A production-style phishing-email classifier that detects malicious emails in real time, explains its decisions through SHAP, LIME, and a built-in NLG engine, and demonstrably resists adversarial attacks generated by LLMs.

---

## Highlights

| | |
|---|---|
| **Live API** | FastAPI endpoint with `/predict`, `/batch_analyze`, `/health` |
| **Two classifiers** | Classical RF + XGBoost ensemble **and** SecBERT fine-tuned transformer |
| **Explainability** | Top-10 SHAP features, LIME token weights, contextual NLG explanation |
| **Adversarial dataset** | 500+ LLM-generated evasive phishing emails across 10 attack categories |
| **Active hardening** | Adversarial training + hard-negative legitimate expansion |
| **Arms race result** | Baseline evasion **95 %** → hardened evasion **~8 %** |
| **No external API keys** | Built-in rule-based NLG engine — runs offline anywhere |

---

## Architecture

```
Email Text
   │
   ▼
Feature Extraction        ┌──────────────────────┐
 • 18 linguistic features │ Classical Ensemble   │
 • 1000-dim TF-IDF        │ RF (500) + XGB (500) │
   │                      └──────────────────────┘
   ├──────────────────────┐
   │                      │
   ▼                      ▼
Predict             SHAP TreeExplainer  →  Top-10 features
                    LIME LimeTextExplainer → Token weights
                                  │
                                  ▼
                         Rule-based NLG engine
                                  │
                                  ▼
                            JSON response
```

## Quick start

### 1. Install

```bash
git clone https://github.com/Humna-Khan/PhishShield-XAI.git
cd PhishShield-XAI
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
```

### 2. Run the API

```bash
# Self-contained (recommended)
python3 -m uvicorn colab_api:app --host 0.0.0.0 --port 8000

# Or via the modular package
python3 -m src.api.app
```

Health check:
```bash
curl http://localhost:8000/health
# {"status":"healthy","model_loaded":true,"version":"1.0.0"}
```

### 3. Try a prediction

```bash
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"email_text":"URGENT: verify your account at https://bit.ly/account-verify"}' \
  | python3 -m json.tool
```

Sample response:
```json
{
  "classification": "phishing",
  "confidence_score": 0.9789,
  "shap_features": [
    {"feature": "tfidf_verify",       "importance": 0.087, "direction": "phishing"},
    {"feature": "suspicious_url_count","importance": 0.068, "direction": "phishing"},
    "..."
  ],
  "lime_highlights": [
    {"token": "verify", "weight":  0.458},
    {"token": "URGENT", "weight":  0.312}
  ],
  "llm_explanation": "This email was classified as phishing with high confidence (98%) based on 10 linguistic and structural signals. The strongest phishing signal was financial / credential trigger words (SHAP: tfidf_verify, weight 0.087). LIME token analysis highlighted 'verify', 'URGENT', 'bit' as primary phishing-indicative terms.",
  "model_used": "classical"
}
```

### 4. Run the acceptance test

```bash
python3 scripts/rigorous_test.py
# 16/16 PASS  ✅
```

### 5. Run the dashboard

```bash
./run.sh                          # API + Vite frontend together
# → API: http://localhost:8000
# → Dashboard: http://localhost:5173
```

## Running the full pipeline (Google Colab)

Open `notebooks/full_pipeline.ipynb` in Colab and run top-to-bottom. The notebook covers all four phases:

| Phase | Cells | What runs |
|-------|-------|-----------|
| 1 — Dataset | 4-5 | Load adversarial samples + synthesise legitimate emails, EDA |
| 2 — Models  | 7-9 | Train RF+XGBoost; fine-tune SecBERT via HF Trainer; compare metrics |
| 3 — Live API | 11-14 | Deploy FastAPI + (optional) pyngrok tunnel; live prediction demo |
| 4 — Arms race | 16-19 | 300-email adversarial attack → SHAP forensics → hardening → re-attack |

> **Tip:** the SecBERT fine-tune cell takes 5-10 min on a T4 GPU. Pre-run it before any live demo.

## Cybersecurity encoder selection

We use **`jackaduma/SecBERT`** — a BERT-base model pre-trained on **1.2 billion tokens** of cybersecurity text:

* CVE descriptions and security advisories
* Threat-intelligence reports
* Malware analysis writeups

Why SecBERT over general BERT/RoBERTa:
1. Domain vocabulary already encoded — *phishing*, *credential*, *spoofing*, *wire transfer*, *invoice* have correct contextual weights
2. Same architecture as BERT-base (768 hidden, 12 heads) → fine-tunes cleanly with HF Trainer API
3. Fits comfortably on a Colab T4 GPU

## Hardening strategies

1. **Adversarial training** — inject 200 evasion-optimised samples as labelled phishing during retraining.
2. **Hard-negative legitimate expansion** — add security-alert-style legitimate emails (password reset notices, MFA prompts) so the model learns the boundary between *security comms* and *credential phishing*.

Both are implemented in Phase 4 of the notebook and the standalone `scripts/generate_artifacts.py`.
